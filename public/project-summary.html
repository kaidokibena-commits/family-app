Probleemid ja lahendused
Probleem Lahendus & õppetund
Faas 3

Mobiilis tehtud ülesanded ei ilmunud arvutis
Lahendus

localStorage on brauseripõhine — andmed ei liigu seadmete vahel. Lahendus: kõik lugemine viia Supabase'i. Õppetund: kui rakendust kasutatakse mitmes seadmes, ei tohi kasutada localStorage'i andmete salvestamiseks.
Faas 3

Rakendus jäi igaveseks "Laen..." seisu pärast Supabase'ile üleminekut
Lahendus

Vercel ei loe .env.local faili — keskkonnamuutujad tuleb käsitsi Vercelisse lisada (vercel env add). Õppetund: pärast igat muudatust keskkonnmuutujates tuleb uuesti deployda.
Faas 3 & 4

Supabase tabel ei olnud API kaudu leitav ("schema cache" viga)
Lahendus

Pärast uue tabeli loomist peab Supabase PostgREST cache'i uuendama. Käsk: NOTIFY pgrst, 'reload schema'; SQL editoris. Õppetund: uus tabel ei ole kohe API kaudu saadaval.
Faas 4

Resend ei saatnud emaile — "can only send to your own email"
Lahendus

Resend'i tasuta plaan ilma verifitseeritud domeenita lubab saata ainult konto omaniku emailile. Õppetund: emailide saatmiseks erinevatele aadressidele on vajalik oma domeen verifitseerida Resend'is.
Faas 4

Gmail aadress punktiga vs ilma (kaido.kibena vs kaidokibena)
Lahendus

Gmail ignoreerib punkte aadressis, kuid Resend teeb string-võrdluse. Tulemuseks: kaido.kibena@gmail.com ≠ kaidokibena@gmail.com Resend'i jaoks. Õppetund: kasuta täpselt sama emaili, millega Resend'i konto on loodud.
Faas 2

Ülesannete reset ei toimunud täpselt Eesti aja järgi
Lahendus

Server töötab UTC ajatsoonis, kasutaja on EEST (UTC+3). Lahendus: Intl.DateTimeFormat koos timeZone: "Europe/Tallinn" — ei tohi eeldada, et serveri aeg = kasutaja aeg.
